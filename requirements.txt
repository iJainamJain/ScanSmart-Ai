# Runtime dependencies. Kept deliberately lean because this is also what
# Streamlit Community Cloud installs on every deploy.
#
# Upper bounds are loose on purpose: pinning below a major version (numpy<2,
# pillow<11) leaves no prebuilt wheel on newer Python runtimes, so pip falls
# back to compiling from source and fails on missing system headers. Streamlit
# Cloud currently defaults to Python 3.14, where that broke the build.
#
# streamlit is the one exception: capped below 1.61 because streamlit_image_
# coordinates 0.4.0 (latest on PyPI) imports the private symbol
# `UseColumnWith` from streamlit.elements.image, which streamlit 1.61.0
# removed. That's a pure-Python wheel either way, so the cap carries none of
# the compile-from-source risk the comment above warns about. Broke the live
# app on 2026-08-06 when Streamlit Cloud auto-picked 1.61.1 on redeploy.
#
# Development-only tools live in requirements-dev.txt.

# headless: no libGL on Streamlit Cloud, and the project makes no cv2 GUI calls
opencv-python-headless>=4.9
numpy>=1.26
pillow>=10.2
matplotlib>=3.8
reportlab>=4.1
pypdf>=4.0
pytesseract>=0.3.10
streamlit>=1.31,<1.61
streamlit-image-coordinates>=0.1.7
